AI 开发效率工具推荐

分享几个日常 AI 辅助开发中非常实用的工具，帮助大家更高效地使用 AI Agent 编程。


—— 1. Wave Terminal —— 多 Agent 并行监控终端

GitHub: https://github.com/wavetermdev/waveterm

一个现代化的终端应用，核心亮点是单窗口内多面板布局，非常适合同时操控多个 AI Agent 工作。

为什么推荐：
· 多面板并行 — 一个窗口内同时开启多个 Claude Code CLI、终端、内置浏览器、Markdown 预览等面板
· Agent 协作枢纽 — 用 Markdown 文件作为多个 Agent 之间的沟通媒介，一屏监控所有 Agent 的工作进度
· 内置 Web 浏览器 — 无需切出终端即可查看文档、PR、部署页面等
· 跨平台 — 支持 macOS / Windows / Linux

—— 2. Claude Code History Viewer —— Session 分析与成本监控

GitHub: https://github.com/jhlee0409/claude-code-history-viewer

一个可视化工具，帮你复盘每一次 Claude Code 会话，精确掌握 Token 消耗和成本。

为什么推荐：
· Session 全览 — 直观查看每次会话的完整交互记录
· Token 成本分析 — 精确统计输入/输出 Token 数、缓存命中率、总花费，帮你优化 prompt 策略
· 趋势追踪 — 按时间维度查看 Token 使用趋势，识别高消耗模式
· 分享与复盘 — 方便团队间分享优秀的 Session 实践
